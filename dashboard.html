      Set up your kit

      Step by step
      1. Plug in the gateway. Cellular gateways only need power. Internet-cable gateways also plug into your router. Place it somewhere central, off the floor.
      2. Mount each sensor outside its unit. Use the magnet or screws, next to the door. The sensor stays outside so the cold doesn't drain its battery.
      3. Run the probe inside. Pass the thin cable along the door seal and clip the probe to a shelf in the middle of the unit, away from the fan and door.
      4. Add each sensor below. Scan the label or type the 16-character sensor ID printed on it, then name the unit. Readings start within a few minutes.
